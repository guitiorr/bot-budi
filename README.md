# Bot Budi

Bot Budi is a Music Bot that i was curious to make back when i was in senior highschool.
The main feature of this bot is to play music, as an alternative to other Discord music bots like Rhythm and Groovy.
I had this idea because Discord music bots were getting deactivated because of copyright issues. So i made my own music bot for private use with me and my friends.
I ended up implementing a Tic Tac Toe game with this bot to play with my friends!

# Playing Music
In order to play music you must be in a voice channel, then you should execute a command for the bot the join the voice channel you are in, then you must queue music that is posted publicly on YouTube and execute the play command then the bot will start to play the music!
